# Rex Snap — Chrome Extension (v1.1)

Disappear from video calls with a particle "snap" effect, on **any website or web app** that uses your webcam.
100% on-device. No account, no upload, no tracking.

## Install (1 minute)
1. Download `RexSnap-Extension.zip` and extract it (you get a `RexSnap` folder).
2. Open `chrome://extensions` (Edge: `edge://extensions`).
3. Turn on **Developer mode** (top-right).
4. Click **Load unpacked** and select the `RexSnap` folder (the one containing `manifest.json`).
5. Pin the extension. Open your meeting, reload the tab once, turn on your camera, then press **Alt+S**.

## Controls
- **Alt + S**: Snap / Return
- Floating **🫰 Snap** button on the page
- Popup: Snap, Return, particle style (dust / sand / embers / glitter), duration, enable switch

## Notes
- Reload the tab once after installing, before turning the camera on.
- Works on Chromium browsers (Chrome, Edge, Brave, Opera).
- Desktop apps (Zoom/Teams desktop clients) are not browser pages and cannot be affected by an extension.
